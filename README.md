# CatanStartPosition
🏝️ CatanStartPosition — Калькулятор оптимальной стартовой позиции для игры «Поселенцы с Катана»
Этот инструмент помогает игрокам в настольную игру «Поселенцы с Катана» (Catan) находить наилучшие места для размещения поселений и городов на основе реальной конфигурации карты.
Поддерживает стандартные и расширенные (5–6 игроков) карты, учёт занятых вершин, а также стратегии «поселение + город».

(пример интерфейса)

# ✨ Возможности
    🎨 Визуальный редактор карты:
        * Интерактивная сетка гексов.
        * Выбор ресурса и числа для каждого гекса.
        * Автоматическая окраска по типу ресурса.
        * Сохранение карты в формате map_data.json.
    🧠 Интеллектуальный расчёт:
        * Учёт вероятностей выпадения чисел (2–12, кроме 7).
        * Расчёт дефицитности ресурсов (редкие ресурсы ценятся выше).
        * Бонус за числа 2 и 12 — они дополнительно повышают ценность ресурса.
        * Поддержка всех типов расчётов:
            Лучшее место для поселения.
            Лучшее место для города.
            Оптимальная пара (поселение + город) с покрытием всех 5 ресурсов.
            Город с учётом вашего уже построенного поселения.
    👥 Учёт игровой ситуации:
        * Возможность указать занятые другими игроками вершины.
        * Динамический пересчёт при изменении условий.
    💻 Полностью GUI-ориентированный:
        * Никакой консоли — всё через интуитивный графический интерфейс (Tkinter).
        * Результаты отображаются в удобном окне с прокруткой.

# 📦 Требования
    Python 3.8+
    Библиотеки: tkinter (входит в стандартную поставку)

# 🚀 Установка и запуск
    Клонируйте репозиторий:
        git clone https://github.com/Micoto12/CatanStartPosition.git
        cd CatanStartPosition
    
    Запустите главное меню:
        python main.py
